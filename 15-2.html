JavaScript 程序结构：循环与条件

程序结构分为三种：顺序结构、条件（分支）结构和循环结构。本页面演示后两种：条件语句 if / else if / else 与循环语句 for / while，以及两者的结合应用。

1. for 循环 —— 求 1+2+…+100 的和

var tang_sum = 0; for (var tang_i = 1; tang_i <= 100; tang_i++) { tang_sum += tang_i; }

2. while 循环 —— 倒计时输出

var tang_n = 5; while (tang_n > 0) { tang_n--; }

3. if / else if / else 条件 —— 成绩等级

if (tang_score >= 90) 等级 = "优秀"; else if (tang_score >= 80) 等级 = "良好"; else if (tang_score >= 60) 等级 = "及格"; else 等级 = "不及格";

4. 循环 + 条件 —— FizzBuzz（1~30）

for (var tang_i = 1; tang_i <= 30; tang_i++) { if (tang_i % 15 === 0) "FizzBuzz"; else if (tang_i % 3 === 0) "Fizz"; else if (tang_i % 5 === 0) "Buzz"; else tang_i; }
