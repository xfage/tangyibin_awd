JavaScript 基本的六种数据类型

使用 typeof 运算符可以检测变量的数据类型。下面六张卡片分别演示了 JavaScript 的六种基本数据类型，卡片中的 绿色结果 由页面中的脚本实时计算得出。

1. String（字符串）

示例：var tang_str = "唐翊斌";

typeof 结果：

用引号（单引号或双引号）括起来的一串字符。

2. Number（数值型）

示例：var tang_num = 3.14;

typeof 结果：

整数和浮点数，不区分整型与浮点型。

3. Boolean（布尔型）

示例：var tang_bool = true;

typeof 结果：

只有两个值：true（真）和 false（假）。

4. Undefined（未定义）

示例：var tang_undef;

typeof 结果：

变量已声明但尚未赋值时的默认值。

5. Null（空值）

示例：var tang_null = null;

typeof 结果：

表示"空"，返回 object 是 JavaScript 的历史遗留特性。

6. Object（对象）

示例：var tang_obj = {name: "唐翊斌"};

typeof 结果：

键值对的集合，函数、数组等也属于对象范畴。
