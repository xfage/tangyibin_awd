# Commit and Push Project

## Instructions


When the user asks to commit and push the project:

1. **Check status**: Run `git status` to see current state
2. **Stage all changes**: Run `git add -A`
3. **Commit**: Run `git commit -m "<message>"` with a descriptive message
4. **Push**: Run `git push -u origin master`

## Repository

- Remote: `https://gitee.com/tyb-2020/tyb_html.git`
- Branch: `master`

## Notes

- If no commits exist yet, this will be the initial commit
- If remote `origin` is not set, add it with: `git remote add origin https://gitee.com/tyb-2020/tyb_html.git`
- After the first push, subsequent pushes can use `git push`
