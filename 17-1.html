JSON 数据格式

JSON（JavaScript Object Notation）——一种轻量的、人人都能读的数据交换格式

怎么玩：本章认识 JSON 是什么、它的六种值类型、与 JS 对象的书写区别， 然后动手体验两件事：把 JS 对象序列化成字符串（JSON.stringify）、把 JSON 字符串解析回对象（JSON.parse）。 下面两个演示都能交互，随时点 重置 还原。
一、认识 JSON：它到底是什么


一种数据格式

不是程序，只是“数据的写法”

JSON 用纯文本描述数据，和语言无关。后端返回它、前端读取它，双方都看得懂。



长得像 JS 对象

但规则更严格

它借用 JS 对象的 { } 和 [ ] 语法，但键必须加双引号、不能写注释、不能写函数。



用于数据交换

网络传输 / 本地存储

接口请求、配置保存、前后端通信，几乎都用 JSON 来打包数据。

二、JSON 里的六种值类型


字符串 string

必须用双引号包裹
"唐翊斌"　"2026-11-02"


数字 number

整数、小数、负数
18　3.14　-7　1e3


布尔 boolean

只有两个值
true　false


空值 null

表示“没有值”
null


数组 array

用 [ ] 的有序集合
[1, 2, 3]　["a", "b"]


对象 object

用 { } 的键值集合
{"name": "小明"}
三、JSON 字符串 ≠ JS 对象（书写规则）
写法JS 对象（合法）JSON（合法）说明
键名 { name: "小明" } { "name": "小明" } JSON 的键必须用双引号
字符串 { "x": 'abc' } { "x": "abc" } JSON 字符串只能用双引号，不可用单引号
注释 { /* 备注 */ a: 1 } 不支持注释 JSON 里不能写注释
函数 { say(){} } 不支持函数 JSON 只能放“数据”，不能放函数/方法
末尾逗号 { a: 1, } 不能有尾逗号 最后一项后不能留逗号
单引号键 / 键无引号 { 'a': 1 } 不合法 键必须双引号包裹
