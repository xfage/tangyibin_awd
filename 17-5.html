JavaScript 定时器

两种最常用的时间控制工具：setTimeout 与 setInterval

怎么玩：下面两个演示都可交互——setTimeout 在设定的延时后只执行一次回调（可中途取消）； setInterval 每隔固定时间就重复执行回调，直到被停止。两个都会返回一个定时器 id，用对应的 clearTimeout / clearInterval 即可取消。
一、两种定时器是什么


setTimeout

延时一次，到点执行

在等待 delay 毫秒后，只运行一次回调函数。适合"几秒后做某事"，如提示框、跳转。

var id = setTimeout(function () { console.log("时间到！"); }, 1500); // 1500 毫秒后执行一次 clearTimeout(id); // 可中途取消


setInterval

每隔一段时间，反复执行

每过 delay 毫秒就重复运行一次回调，直到被清除。适合时钟、轮播、倒计时。

var id = setInterval(function () { console.log("滴答"); }, 1000); // 每 1000 毫秒执行一次 clearInterval(id); // 停止重复执行
二、setTimeout 演示：延时点亮

状态：未启动　定时器 id：无

点击「启动」，灯泡会在设定毫秒后点亮；「取消」会调用 clearTimeout 中止它，灯泡保持熄灭。

三、setInterval 演示：实时时钟
--:--:--
已运行：0 秒　（setInterval 每 1 秒滴答一次）
状态：未启动　定时器 id：无

点击「启动」，时钟每秒刷新一次并累加秒数；「停止」调用 clearInterval 结束重复。

四、一句话对比
🔹 setTimeout：等一会儿，只做一次。 🔹 setInterval：每隔一会儿，反复做，直到被清除。

两者都返回数字 id；取消分别用 clearTimeout(id) 与 clearInterval(id)。注意：延时参数单位是毫秒（1000 毫秒 = 1 秒）。
