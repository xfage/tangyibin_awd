ECharts 从左到右树状图

官方示例 tree-basic · 嵌套数据 + 可折叠层级结构

说明：ECharts 库已下载到 cdn/echarts.min.js，本页只做本地引用，不访问在线 CDN。 树状图用嵌套的 name / children 数据描述层级，orient: 'LR' 让根节点在左、叶子在右； 点击节点可展开或折叠，鼠标悬停可高亮整条子树。
ECharts 5.6.0 本地文件 · 单图表页面

图像识别科研系统模块树

根节点在左 · 可点击节点折叠 / 展开 · 可拖拽缩放

NODES / 节点总数--含根节点与全部叶子
DEPTH / 层级深度--从根节点算起
LEAVES / 叶子模块--没有子节点的末端模块

实现要点TREE · LEFT TO RIGHT

嵌套树形数据

每个节点是一个含 name 与 children 的对象，series.type: 'tree' 会按层级自动计算坐标。

从左到右布局

orient: 'LR' 决定方向；内部节点标签左对齐（右对齐文字），leaves 标签改为右侧显示。

交互与导出

expandAndCollapse 支持折叠、roam 支持缩放平移、emphasis.focus: 'descendant' 高亮子树；getDataURL 导出 PNG。

核心代码

// 1. 本地引入 ECharts，初始化图表实例 <script src="cdn/echarts.min.js"></script> var tang_chart = window.echarts.init(document.getElementById('tang_tree')); // 2. 嵌套结构描述层级 var tang_tree_data = [{ name: '图像识别科研系统', children: [{ name: '数据与标注', children: [{ name: '多源图像采集' }, ...] }, ...] }]; // 3. 关键配置：LR 方向、可折叠、叶子标签在右 tang_chart.setOption({ series: [{ type: 'tree', data: tang_tree_data, orient: 'LR', expandAndCollapse: true, initialTreeDepth: 2, roam: true, label: { position: 'left', align: 'right' }, leaves: { label: { position: 'right', align: 'left' } }, emphasis: { focus: 'descendant' } }] });
