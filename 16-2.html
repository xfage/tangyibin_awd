JavaScript 对象（Object）

把对象想象成一张“贴了标签的档案卡”——每个标签（键 key）对应一格内容（值 value）

怎么玩：下面这张档案卡就是一个 JavaScript 对象。点击任意操作的 运行 按钮， 带 改原对象 标签的操作会直接增删改卡片里的字段； 带 返回结果 标签的操作只在卡片里展示结果，不改动卡片。 随时点 重置 还原。
当前对象 obj（一张档案卡）

一、认识对象：创建与访问

对象字面量 创建
用 { } 直接写出 键: 值，就是最常用创建方式。
var obj = { name: "小明", age: 18, hobby: "篮球" };
↑ 上面这张档案卡就是用它创建的

点表示法 读取
用 对象.键 读取某个属性的值。
obj.name

方括号表示法 读取
用 对象["键"] 读取，键可以是变量或带连字符。
obj["age"]

属性是否存在 判断
用 "键" in 对象 判断某个属性在不在。
"city" in obj
二、增删改属性（改变原对象）

添加属性 改原对象
直接赋值就能新增一个字段（如 gender）。
obj.gender = "男"

修改属性 改原对象
给已有的键重新赋值即可覆盖。
obj.age = 19

删除属性 改原对象
用 delete 运算符删除某个字段。
delete obj.hobby

属性个数 查看
Object.keys(obj).length 得到字段数量。
Object.keys(obj).length
三、对象的方法与 this

对象的方法 函数属性
属性的值可以是一个函数，称为“方法”。
obj.sayHi = function () { return "你好，我是" + this.name; };
方法调用见下方“this 关键字”

this 关键字 指向本身
方法里的 this 指向“调用它的那个对象”。
obj.sayHi() // this = obj
四、遍历与批量操作（不改变原对象）

for...in 遍历 遍历键
依次拿到对象的所有键名。
for (var k in obj) { ... }

Object.keys() 返回数组
取出所有键名组成一个数组。
Object.keys(obj)

Object.values() 返回数组
取出所有值组成一个数组。
Object.values(obj)

Object.entries() 返回键值对
取出 [键, 值] 组成的数组。
Object.entries(obj)
五、序列化与嵌套对象

JSON.stringify() 序列化成字符串
把对象转成 JSON 字符串，便于存储/传输。
JSON.stringify(obj)

JSON.parse() 解析成对象
把 JSON 字符串还原成对象。
JSON.parse('{"x":1,"y":2}')

嵌套对象 对象里套对象
对象的值还可以是另一个对象，用 对象.键.子键 访问。
var tang_stu = { name: "小红", addr: { province: "上海", district: "浦东" } }; tang_stu.addr.district // "浦东"
