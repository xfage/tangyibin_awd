架构分层说明SIX LAYERS

01 / USER ACCESS

用户访问层

PC 浏览器、手机 H5、微信小程序、馆内自助终端与无障碍版本，覆盖到馆与在线两类读者。

02 / EDGE & SECURITY

接入与安全层

CDN 静态加速、WAF 防火墙、Nginx 负载均衡与 HTTPS 证书共同承接公网流量，兼顾速度与安全。

03 / APPLICATION

应用服务层

门户网站、OPAC 馆藏检索、读者中心、数字资源、活动预约、参考咨询等 8 个核心业务模块。

04 / COMMON SERVICE

公共服务层

统一身份认证 SSO、短信邮件、微信开放接口、在线支付与日志审计等可复用的通用能力。

05 / DATA & CACHE

数据与缓存层

MySQL 业务库、Redis 缓存、Elasticsearch 检索索引、MinIO 对象存储与备份归档。

06 / INFRASTRUCTURE

基础设施层

应用与数据库服务器集群、监控告警、容灾备份与馆内专线，构成全站稳定运行的底座。

Canvas 绘制要点

  • 坐标体系：以 1180 × 880 的逻辑坐标绘图，按容器宽度等比缩放，高清屏自动乘 devicePixelRatio。
  • 圆角矩形：用 arcTo 绘制卡片与分层色条，浅色底 + 描边区分六个层级。
  • 连接链路：线性渐变 + 动态虚线与箭头表示层间调用，循环光点表示上下行数据流。
  • 交互命中：pointermove 换算逻辑坐标后做矩形命中检测，悬停高亮模块并绘制说明浮层。
  • 导出图片：离屏 canvas 以 2 倍分辨率重绘整张图，toDataURL 导出 PNG。
  • 自适应：窄屏时画布保持最小宽度并在容器内横向滚动，保证模块文字清晰可读。
// 高清屏适配：逻辑坐标 × 缩放比 tang_ctx.setTransform(tang_w / 1180, 0, 0, tang_h / 880, 0, 0); tang_rr(tang_ctx, x, y, w, h, 10); // arcTo 圆角矩形 tang_ctx.fillStyle = "#ffffff"; tang_ctx.fill(); tang_ctx.setLineDash([5, 5]); // 层间流动虚线 tang_ctx.lineDashOffset = -(tang_clock * 0.03); tang_ctx.stroke();
