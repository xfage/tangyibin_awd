ECharts 笛卡尔坐标系热力图

官方示例 heatmap-cartesian · 类目轴 + 连续型视觉映射

说明：ECharts 库已下载到 cdn/echarts.min.js，本页只做本地引用，不访问在线 CDN。 热力图把「星期 × 小时」作为两个 category 类目轴，每个格子的数据为 [x 索引, y 索引, 数值]；visualMap 负责把数值映射成颜色。

实现要点CARTESIAN HEATMAP

笛卡尔坐标系

x 轴为 24 个小时、y 轴为周一到周日，二者都是 type: 'category' 类目轴；splitArea 让网格更易读。

visualMap 映射

连续型 visualMap 把 0–100 的数值映射为渐变色，calculable: true 时拖动两端手柄可筛选数据区间。

交互与自适应

tooltip 显示精确数值；按钮控制数据、标签和配色；窗口尺寸变化时调用 chart.resize() 重排。

核心代码

// 1. 本地引入 ECharts，初始化图表实例 <script src="cdn/echarts.min.js"></script> var tang_chart = window.echarts.init(document.getElementById('tang_heatmap')); // 2. 热力图数据：[x 索引, y 索引, 数值] var tang_data = [[0, 0, 12], [1, 0, 8], ...]; // 3. 配置类目轴、视觉映射与热力图系列 tang_chart.setOption({ xAxis: { type: 'category', data: tang_hours }, yAxis: { type: 'category', data: tang_days }, visualMap: { min: 0, max: 100, calculable: true, orient: 'horizontal' }, series: [{ type: 'heatmap', data: tang_data, label: { show: true } }] }); window.addEventListener('resize', function () { tang_chart.resize(); });
