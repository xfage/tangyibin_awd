JavaScript 数组的常用方法

把数组想象成一排彩色盒子 —— 每个方法就是对这排盒子的一次“操作”

怎么玩：下面这排盒子就是当前的数组。点击任意方法的 运行 按钮， 带 改原数组 标签的方法会直接改变上面的盒子； 带 返回新数组 标签的方法不会改动原数组，只在卡片里展示结果。 随时点 重置 还原。
当前数组 arr
一、增删与修改（改变原数组）

push() 改原数组
在数组末尾追加一个元素，返回新长度。
arr.push(新元素)

pop() 改原数组
删除并返回数组末尾的元素。
var tang_v = arr.pop()

unshift() 改原数组
在数组开头插入一个元素，返回新长度。
arr.unshift(新元素)

shift() 改原数组
删除并返回数组开头的元素。
var tang_v = arr.shift()

splice() 改原数组
在任意位置删除/插入元素，返回被删除的部分。
arr.splice(2, 1, 新元素)

slice() 返回新数组
截取 [start, end) 区间，不改变原数组。
arr.slice(1, 3)
二、查询、提取与合并（不改变原数组）

concat() 返回新数组
合并多个数组，原数组保持不变。
arr.concat([11, 22])

join() 返回字符串
用分隔符把元素拼成一个字符串。
arr.join("-")

indexOf() 返回索引
查找元素首次出现的位置，找不到返回 -1。
arr.indexOf(9)

includes() 返回布尔
判断数组是否包含某个元素。
arr.includes(5)

find() 返回元素
返回第一个满足条件的元素。
arr.find(x => x > 5)

forEach() 仅遍历
对每一个元素执行一次回调，无返回值。
arr.forEach((v, i) => ...)
三、遍历与生成新数组（不改变原数组）

map() 返回新数组
对每个元素计算后生成同长度的新数组。
arr.map(x => x * 2)

filter() 返回新数组
筛选出满足条件的元素组成新数组。
arr.filter(x => x > 4)

reduce() 返回累计值
把数组“累积”成一个值，例如求和。
arr.reduce((s, x) => s + x, 0)

reverse() 改原数组
原地反转数组的元素顺序。
arr.reverse()

sort() 改原数组
按比较函数排序（此处从小到大）。
arr.sort((a, b) => a - b)

length 属性
数组的元素个数，可读取也可修改。
arr.length
