Canvas 粒子文字动画

把「唐翊斌」三个字拆成像素点，再用粒子重新聚合成字

原理：先在离屏 canvas 上绘制文字，用 getImageData() 按步长采样笔画像素， 每个采样点生成一个粒子；粒子在弹簧模型下回到目标点，鼠标靠近时被推开，点击画布则爆散重聚。
PARTICLES 0
FPS --
PALETTE 橙青
移动鼠标推开粒子 · 点击画面爆散重聚
Canvas 2D + requestAnimationFrame · 无第三方库

文字 → 像素点

用离屏 canvas 居中绘制「唐翊斌」，再读取 ImageData，每隔 2–4 个像素取一个不透明的点，得到数千个笔画坐标。

弹簧模型

粒子记录当前位置与目标位置，速度按 v = (v + 偏移 × 0.03) × 0.9 迭代，形成回弹；鼠标半径内的粒子受到斥力。

逐帧绘制

requestAnimationFrame 每帧清屏重绘背景、光晕、粒子与尾迹，并按帧间隔缩放速度，高刷新率屏幕也不会加速。

核心代码

// 1. 离屏绘制文字，采样笔画像素 tang_o.font = '700 ' + tang_fs + 'px "Microsoft YaHei"'; tang_o.fillStyle = '#fff'; tang_o.fillText('唐翊斌', tang_cx, tang_cy); var tang_data = tang_o.getImageData(0, 0, tang_W, tang_H).data; if (tang_data[(tang_y * tang_W + tang_x) * 4 + 3] > 130) { tang_pts.push(tang_x, tang_y); // 得到一个粒子目标点 } // 2. 每帧让粒子向目标点回弹 tang_p.vx = (tang_p.vx + (tang_p.tx - tang_p.x) * 0.03) * 0.9; tang_p.vy = (tang_p.vy + (tang_p.ty - tang_p.y) * 0.03) * 0.9; tang_p.x += tang_p.vx; tang_p.y += tang_p.vy;
